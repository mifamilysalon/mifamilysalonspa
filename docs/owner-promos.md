# How to manage promos (owner)

Publish time-limited offers on the website without calling a developer.

## Create an offer

1. Sign in at **Admin** → **Promos**.
2. Fill in:
   - **Title** — short headline (e.g. “20% off color this week”)
   - **Details** — optional short description
   - **Button text / link** — optional (e.g. “Book now” → `/appointments`, or a phone `tel:` link)
   - **Start date** and **End date** — the offer only shows between these dates
   - **Where it shows** — Homepage banner, Offers page, or both
   - **Featured** — use for the main homepage banner (only one featured at a time)
3. Leave **Active** checked and save.
4. Confirm on the site:
   - Homepage (banner below the hero, if placement includes banner)
   - [/offers](/offers)

## End or hide an offer

- **Wait for the end date** — it disappears automatically after that day, or
- Open the promo in Admin → uncheck **Active** → save, or
- Delete the promo if you no longer need it.

## Tips

- Keep copy short; the homepage banner is a slim strip, not a full campaign page.
- Prices stay brochure/desk-only — promos are marketing messages, not automatic discounts at booking.
- For Instagram/Facebook blasts, still post there; use the site banner so walk-in and web visitors see the same offer.
